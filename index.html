ASTMA — Social & media analytics

Review text is classified as positive, neutral or negative using transparent keyword rules. Aggregate sentiment and rating patterns help identify recurring service issues.

Example decision-support report

If negative feedback frequently mentions “late”, “cold” or “delay”, management should review delivery preparation and dispatch time. If positive feedback mentions “delicious” or “fresh”, preserve food quality practices. Review categories can help decide which operational area needs attention first.

Project limitation: Current version is a front-end academic prototype using sample data and browser-local storage. It does not connect to real restaurant platforms, payments, or a shared enterprise database.
